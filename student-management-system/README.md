# Student Management System
A simple **Java Console-Based Student Management System** that performs basic CRUD (Create, Read, Update, Delete) operations using **ArrayList**. This project is built to strengthen Core Java concepts, Object-Oriented Programming (OOP), Collections Framework, and problem-solving skills through hands-on implementation.
