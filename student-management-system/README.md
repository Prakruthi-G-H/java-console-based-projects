# Student Management System
A menu-driven Java console application that allows users to manage student records through CRUD (Create, Read, Update, Delete) operations.

# Application Overview
The Student Management System provides a simple way to maintain student information. Users can add, view, search, update, and delete student records through an interactive console menu.

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Java | Core programming language |
| Object-Oriented Programming (OOP) | Code organization and design principles |
| Java Collections Framework (ArrayList) | In-memory data storage |
| Scanner | User input handling |
| Eclipse IDE | Development environment |

## Key Features
- Add Student: Add new student records
- View Students: Display the available student records
- Search Student: Search for a student record
- Update Student: Modify existing student information
- Delete Student: Remove a student record

## Student Information

Each record contains:
- Student ID
- Student Name
- Age
- Course
