# java-console-based-projects
A growing collection of Java console-based projects built from scratch to strengthen core programming skills. This repository focuses on object-oriented programming (OOP), problem-solving, logical thinking, clean code practices, and real-world application development. Each project is designed to reinforce fundamental Java concepts through hands-on implementation, with new projects added as the learning journey continues.

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Java | Core programming language |
| OOP | Object-oriented design and implementation |
| ArrayList | In-memory storage and CRUD operations |
| Scanner | User input handling |
| Eclipse IDE | Development environment |
