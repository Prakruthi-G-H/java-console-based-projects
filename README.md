# java-console-based-projects

A collection of Java console-based projects developed to strengthen programming fundamentals, object-oriented programming (OOP), logical thinking, and problem-solving skills.
This repository contains beginner-friendly projects built from scratch, focusing on practical implementation of Core Java concepts and clean coding practices

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Java | Core programming language |
| Object-Oriented Programming (OOP) | Code organization and design principles |
| Java Collections Framework (ArrayList) | In-memory data storage |
| Scanner | User input handling |
| Eclipse IDE | Development environment |

## 📂 Projects

1. Student Management System
   A console-based Java application that allows users to manage student records through a menu-driven interface
 Features:
   - Add student details
   - View student records
   - Search for a student
   - Update student information
   - Delete student records
   - Exit the application

Student Details:
   - Student ID
   - Student Name
   - Age
   - Course

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Prakruthi-G-H/java-console-based-projects.git
   ```
2. Open the project in Eclipse, IntelliJ IDEA, or VS Code.
3. Navigate to:
   ```bash
   student-management-system/src/com/student/
   ```
4. Run the StudentManagementSystem.java file.
